# Tower Toppler '26

A **2026 mobile-first reimagining** of the classic Atari 7800 game **Tower Toppler** (*Nebulus*).

## Features
- **Mobile-Only Touch Controls**: Ergonomic multi-touch virtual D-Pad + dedicated **JUMP** and **FIRE** buttons with subtle haptic feedback.
- **True 16-Column Cylindrical 3D Projection**: Smooth 60fps tower rotation, extruded ledges, cylindrical depth shading, and toxic alien ocean reflections.
- **All 8 Classic Towers**:
  1. The Tower of Eyes
  2. The Realm of Robots
  3. Trap of Tricks
  4. Slippery Slide
  5. Broken Path
  6. Swimmer's Delight
  7. Nasty One
  8. Edge of Doom
- **Complete Classic Mechanics**: Normal, crumbling, ice, conveyor, and destructible block ledges; recallable elevators; dark tunnels & trick doors; snowball gun; mutant molecules, rolling cannonballs, bouncing balls, and floating eyes; tower destruction sequence; and the **MK.7 Mini-Submarine** underwater bonus stage.
- **Zero Dependencies**: Pure HTML5 Canvas, ES Modules, and Web Audio API retro-modern synthesizer.
